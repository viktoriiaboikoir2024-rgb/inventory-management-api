# Автомасштабування

## Налаштування
- Сервіс: ECS Fargate, `inventory-cluster`, задача 0,25 vCPU / 512 MB.
- Application Auto Scaling: мінімум 1, максимум 4 задачі.
- Політика: target tracking за середнім CPU, ціль **60%**.
- Конфігурація описана в Terraform (`terraform/`), `desired_count` ігнорується через `ignore_changes`.

## Результат (прогін A, 80 VUs, кеш вимкнений)
- CPU піднявся до ~83% (лінія цілі 60% перетнута).
- Кількість задач: 1 -> 2 -> 3, після спаду навантаження 3 -> 2 -> 1.
- Час подій (UTC, за дашбордом): scale-out близько 19:25-19:30, scale-in близько 19:40-20:00. Точний час: [ВСТАВИТИ з ECS Events].

## Висновок
Політика спрацювала в обидва боки: сервіс масштабувався вгору при CPU > 60% і повернувся до 1 задачі після спаду. Невелика задача (0,25 vCPU) швидко впирається в CPU, тому масштабування помітне вже при 80 VUs. Масштабування відбувається із запізненням (нові задачі стартують і проходять health-check), тому на піку затримки зростають.
